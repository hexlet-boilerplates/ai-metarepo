# Глоссарий

Термины, которыми пользуются документы и правила этого репозитория.

| Термин | Значение |
| --- | --- |
| Метарепозиторий | Репозиторий, который хранит общие правила, спеки и проверки и держит внутри клоны других репозиториев. Кода продукта в нём нет. |
| Клон | Каталог в `repos/` со своим `.git`. Метарепозиторий его не отслеживает. |
| Шаблон | Репозиторий из организации hexlet-boilerplates, с которого начинают проект. |
| Контракт | Требование из `specs/`, которое одинаково для всех шаблонов и проверяется командой `mise run check`. |
| Worktree | Дополнительный рабочий каталог одного клона на отдельной ветке. Создаётся задачей `mise run worktree`. |
| Правило | Проверка `ast-grep` в `ast-grep/rules/` с тестом в `ast-grep/rule-tests/`. |
| ADR | Запись о решении в `docs/adr/`, у неё есть номер и статус. |
