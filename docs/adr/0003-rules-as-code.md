# Общие правила проверяются кодом

Правило, которое действует на несколько клонов, записывается правилом `ast-grep` с тестом или шагом в `mise run check`. `AGENTS.md` и спеки ссылаются на проверку, но не подменяют её текстом.

## Considered Options

**Правило в `AGENTS.md` словами.** Агент может его не прочитать, прочитать неточно или забыть к концу длинной сессии. Если правило нарушено, об этом узнают на ревью.

**Правило в хуке pre-commit.** Хук метарепозитория не срабатывает в клонах, у них свой `.git` (`docs/agents/tooling.md`). Для проверки клонов он не годится.

**Правило `ast-grep` и задача `mise run check` (выбрано).** Проверка не зависит от того, что прочитал агент, и запускается по всем клонам одной командой.

## Consequences

- Каждое общее правило стоит двух файлов, правила и теста. Это цена, и она оправдана только для требований, которые правда повторяются в нескольких клонах.
- `mise run check` падает, пока в клонах есть нарушения. Исправление относится к клону, а не к метарепозиторию.
- Требование, которое нельзя проверить кодом, остаётся в спеке с пометкой, что проверки у него нет, или не записывается вовсе.
