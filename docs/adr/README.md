## Формат

Файл называется `<номер>-<слаг>.md`, номер четырёхзначный и не переиспользуется. В шапке `status: accepted`, при пересмотре старое решение получает `superseded` и ссылку на новое, а не удаляется. Заголовок формулирует само решение. Дальше идут абзац с решением и причиной, раздел «Considered Options» с отвергнутыми вариантами и раздел «Consequences» с ценой.

Запись нужна, чтобы агент не пересматривал принятое решение заново. Вариант, который уже рассматривали и отвергли, записан вместе с причиной, и агент не предложит его снова.
