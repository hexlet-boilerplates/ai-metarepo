# Клоны задаются секцией [bootstrap.repos] в mise, а не ghorg и не submodules

Шаблоны перечислены в `[bootstrap.repos]` в `mise.toml`, ключ это путь клона, значение это адрес. Клонирует `mise bootstrap repos apply` (задача `mise run clone`), обновляет задача `mise run pull`, которая выполняет в каждом клоне `git pull --rebase --autostash`. Каталог `repos/` лежит в `.gitignore`, метарепозиторий не хранит коммиты клонов. Решение заменяет [ADR 0001](0001-clones-via-ghorg-not-submodules.md).

## Considered Options

**ghorg с `--no-clean` (решение ADR 0001).** Выбирает репозитории организации по регулярному выражению. Список из четырёх имён и так статичен, а ghorg добавляет отдельный инструмент, токен из `gh auth login` и конфиг. Без флага `--no-clean` он по умолчанию стирает неоформленные правки в клонах, и этот флаг приходилось защищать правилом в `AGENTS.md`.

**Git submodules.** Фиксируют коммит каждого клона и дают воспроизводимую пару «спека плюс код». Остаются отвергнутыми по причинам ADR 0001. Submodule после `git submodule update` оказывается в detached HEAD, забытый push подмодуля оставляет метарепозиторий ссылаться на коммит, которого нет на сервере, а `git status` в корне показывает изменения клонов в виде «modified content».

**`[bootstrap.repos]` (выбрано).** Манифест лежит в `mise.toml` рядом с инструментами и не вводит нового инструмента. Публичные адреса клонируются без токена. По документации mise не перезаписывает локальную работу ([bootstrap/repos](https://mise.jdx.dev/bootstrap/repos.html#protect-local-work)), и при проверке запуском `update` на клоне с правкой остановился с ошибкой, а `update --skip-dirty` обновил остальные клоны и оставил правку на месте.

## Consequences

- Версия клона равна моменту клонирования. Воспроизводимости по коммитам нет, и если она понадобится, решение пересматривается в пользу submodules.
- `mise bootstrap repos update` делает fast-forward и пропускает клоны с правками, поэтому для `pull` он не используется. Обновление идёт через `git pull --rebase --autostash`, как требует `AGENTS.md`, а конфликты и забытый stash задача выводит списком.
- Нужна версия mise не ниже 2026.9.6 (`min_version` в `mise.toml`).
- Список клонов дублируется в таблице `repos/README.md`, и при правке `mise.toml` таблицу нужно поправить вместе с ним.
- ghorg и `gh` из `[tools]` убраны, `.ghorg.conf.yaml` удалён.
