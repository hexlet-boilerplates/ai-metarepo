# docs/agents

Правила для агента. `AGENTS.md` в корне короткий и работает как навигация, а подробности лежат здесь. Агент читает документ, когда работа попадает в его область (таблица «Навигация» в `AGENTS.md`).

| Документ | Когда читать |
| --- | --- |
| [repository-layout.md](repository-layout.md) | До работы с клонами и при выборе места запуска агента |
| [worktrees.md](worktrees.md) | Когда задач несколько или нужна изоляция правок |
| [tooling.md](tooling.md) | Перед правкой `mise.toml`, хуков и правил `ast-grep` |
| [agent-settings.md](agent-settings.md) | Перед правкой `.claude/`, `.agents/`, разрешений и MCP |

## Как писать документы в этом каталоге

Документ отвечает на один вопрос и начинается с него. Правила пишутся утверждениями, у каждого есть причина. Всё, что проверяется командой, называет эту команду. Дублировать текст `AGENTS.md` не нужно, достаточно ссылки.
