# Настройки агента

Документ читается перед правкой `.claude/`, `.agents/`, разрешений и подключением MCP.

## Что где лежит

| Путь | Назначение |
| --- | --- |
| `AGENTS.md` | Правила, читаются Claude Code и Codex |
| `.claude/settings.json` | Разрешения и запреты Claude Code для сессий, запущенных из корня |
| `.claude/settings.local.json` | Личные настройки, в `.gitignore` |
| `.agents/skills/` | Скиллы, по каталогу на скилл |
| `.claude/skills` | Ссылка на `.agents/skills`, чтобы Claude Code видел те же скиллы |

## AGENTS.md без CLAUDE.md

Claude Code читает `AGENTS.md` сам с версии 2.1.277 ([документация](https://code.claude.com/docs/en/memory#agents-md)). Условие жёсткое. Если в рабочем каталоге или выше есть `CLAUDE.md`, `.claude/CLAUDE.md` или `CLAUDE.local.md`, чтение `AGENTS.md` отключается. Личный `CLAUDE.local.md` разработчика тоже отключает его, поэтому его не заводят. Загрузку проверяют командой `/context` или по строке `AGENTS.md loaded` в начале сессии. Обоснование решения в [ADR 0002](../adr/0002-only-agents-md.md).

## Запреты в settings.json

`.claude/settings.json` закрывает `git push` и чтение `.env`. Запреты работают при запуске из корня метарепозитория. Настройки клонов оттуда не читаются, а настройки метарепозитория не действуют при запуске из клона. Запрет в настройках дополняет правило из `AGENTS.md`, пропустить его можно, сменив каталог запуска.

## Скиллы

Скилл это каталог с `SKILL.md`, где в шапке `name` и `description`. Описание решает, когда агент подгрузит скилл, поэтому оно называет ситуацию, а не пересказывает содержимое. Здесь один скилл, `add-ast-grep-rule`, он ведёт от идеи правила до теста.

## MCP

Сервер MCP подключают файлом `.mcp.json` в корне, команда `claude mcp add --scope project` его создаёт. В этом репозитории файла нет, подключается по необходимости.

Если сервер подключается, правила такие.

- Права сервера соответствуют задаче, лучше только чтение.
- Токены не коммитятся, они берутся из окружения.
- Сервер, который открывает продакшен, записывается в ADR вместе с границами доступа.
