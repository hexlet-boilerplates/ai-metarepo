# docs

Документы метарепозитория. Они делятся по читателю.

| Каталог | Читатель | О чём |
| --- | --- | --- |
| [agents/](agents/README.md) | Агент | Правила работы, которые не умещаются в `AGENTS.md` |
| [adr/](adr/README.md) | Агент и человек | Решения, которые действуют на все репозитории, и причины |

Спеки и контракты шаблонов лежат отдельно, в [../specs/](../specs/README.md). Документ в `docs/` объясняет, как работать, документ в `specs/` описывает, чему должен соответствовать шаблон.

Если документ становится правилом, которое можно проверить кодом, правило переезжает в `ast-grep/`, а документ ссылается на него.
