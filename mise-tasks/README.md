# mise-tasks

Каждая задача лежит отдельным исполняемым файлом. Имя файла это имя задачи, `mise run clone` запускает `mise-tasks/clone`.

## Задачи

| Файл | Что делает |
| --- | --- |
| `setup` | `mise install` и `hk install` |
| `clone` | Клонирует шаблоны через ghorg с токеном из `gh auth token` |
| `pull` | `git pull --rebase --autostash` в каждом клоне |
| `status` | Ветка и число изменённых файлов в каждом клоне |
| `check` | Тесты правил, `ast-grep scan` по клонам, проверка контракта |
| `worktree` | Worktree под задачу в клоне |
| `worktree-remove` | Удаление такого worktree |

## Как добавить задачу

Создайте файл с shebang `#!/usr/bin/env bash`, строкой `#MISE description="..."` и правами на исполнение (`chmod +x`). Аргументы объявляются строками `#USAGE arg "<имя>"`, значение приходит в переменной `usage_<имя>`. Первой командой стоит `cd "$MISE_CONFIG_ROOT"`, потому что задача может быть запущена из любого каталога.

Проверка синтаксиса при коммите идёт через хук `mise-tasks` в `hk.pkl`.
