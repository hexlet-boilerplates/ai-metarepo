# mise-tasks

Каждая задача лежит отдельным исполняемым файлом. Имя файла это имя задачи, `mise run clone` запускает `mise-tasks/clone`.

## Задачи

| Файл | Что делает |
| --- | --- |
| `setup` | `hk install --mise` |
| `clone` | `mise bootstrap repos apply`, клонирует шаблоны из `[bootstrap.repos]` |
| `pull` | `mise bootstrap repos update --skip-dirty`, клоны с правками пропускает |
| `status` | Ветка и число изменённых файлов в каждом клоне |
| `check` | Тесты правил, `ast-grep scan` по клонам, проверка контракта |
| `worktree` | Worktree под задачу в клоне |
| `worktree-remove` | Удаление такого worktree |

## Как добавить задачу

Создайте файл с shebang `#!/usr/bin/env bash`, строкой `#MISE description="..."` и правами на исполнение (`chmod +x`). Аргументы объявляются строками `#USAGE arg "<имя>"`, значение приходит в переменной `usage_<имя>`. Задача выполняется с рабочим каталогом в корне метарепозитория, даже если `mise run` вызван из клона. Каталог вызова хранит `MISE_ORIGINAL_CWD`. Задача клона с тем же именем перекрывает задачу метарепозитория.

Проверка синтаксиса при коммите идёт через хук `mise-tasks` в `hk.pkl`.
