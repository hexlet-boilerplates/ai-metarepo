# AGENTS.md

Метарепозиторий для шаблонов hexlet-boilerplates. Здесь лежат правила, спеки, решения и проверки. Код шаблонов лежит в клонах `repos/<имя>/`, у каждого клона свой git и свой `AGENTS.md`.

Запускай агента из корня этого репозитория. Из клона правила корня видны не всем инструментам (`docs/agents/repository-layout.md`).

## Git

- До правки в любом репозитории выполни `git branch --show-current` и `git pull --rebase --autostash` в нём. Правило действует для каждого репозитория, который затрагивает задача.
- Git-команды выполняются внутри каталога того репозитория, которого касаются: `git -C repos/<имя> ...`. В корне `git` относится только к самому метарепозиторию.
- Коммит требует явного подтверждения пользователя. Push требует отдельного явного запроса. Разрешение в текущей сессии учитывается при следующих шагах той же работы.
- Сообщение коммита пишется по Conventional Commits, описание на русском, в scope имя шаблона, например `fix(nodejs-package): убрать console.log`.
- Параллельные задачи идут в worktrees (`docs/agents/worktrees.md`), каталог клона не используется как рабочий для двух задач сразу.

## Клоны

- Клонирует `mise run clone`, обновляет `mise run pull`. Список клонов задаёт `[bootstrap.repos]` в `mise.toml` (ADR 0004). После `pull` ищи конфликты и `git stash list` в клоне, прежде чем коммитить: autostash при конфликте оставляет маркеры в файлах.
- `repos/` в `.gitignore`. Файлы клонов коммитятся в их репозиториях, не в этот.
- Не создавай `CLAUDE.md`, `CLAUDE.local.md` и `.claude/CLAUDE.md`. Любой из них отключает чтение `AGENTS.md` в Claude Code (ADR 0002).

## Проверки

- Общие правила проверяет код. Команда `mise run check` запускает тесты правил, `ast-grep scan` по клонам и контракт из `specs/`.
- Новое общее правило оформляется правилом `ast-grep` с тестом, а не строкой в этом файле. Порядок описан в скилле `add-ast-grep-rule`.
- Находку в клоне исправляй в клоне, правило метарепозитория без обсуждения не ослабляй.

## Тексты

Тексты для людей пиши по-русски, без тире и двоеточий в предложениях, абзац одной строкой. Термины из `GLOSSARY.md`.
