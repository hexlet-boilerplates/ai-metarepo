# Добавить правило ast-grep

Правило и тест создаются вместе, правило без теста не коммитится.

1. Определи, что именно запрещено, и найди пример нарушения в клонах командой `ast-grep run --pattern '<шаблон>' --lang <язык> repos/<имя>`. Если нарушений нет, правило проверяется только тестом.
2. Создай `ast-grep/rules/<id>.yml`. Поля `id` (совпадает с именем файла), `language`, `severity` (по умолчанию `error`), `message` (что не так и что делать), `rule.pattern`. Исключения, где нарушение допустимо, выноси в `ignores`. В шапке файла комментарий отвечает на вопрос, почему правило есть. Для второго языка нужен второй файл.
3. Создай `ast-grep/rule-tests/<id>-test.yml` с полем `id` и списками `valid` и `invalid`, минимум по два примера в каждом.
4. Запусти `ast-grep test --skip-snapshot-tests`, затем `mise run check`. Если check упал на клонах, нарушения исправляются в клонах отдельными коммитами, а не ослаблением правила.
5. Если правило отражает требование к шаблонам, добавь его в `specs/boilerplate-conventions.md` со ссылкой на файл правила. Если оно меняет решение для всех репозиториев, запиши ADR в `docs/adr/`.
6. Коммит правила идёт с подтверждением пользователя. Сообщение по Conventional Commits, scope `ast-grep`.
