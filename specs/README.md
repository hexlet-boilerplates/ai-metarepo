# specs

Спеки и контракты, общие для всех шаблонов. Агент читает их до правки клона, а проверка `mise run check` сверяет клоны с ними.

## Что здесь лежит

| Файл | О чём |
| --- | --- |
| [boilerplate-conventions.md](boilerplate-conventions.md) | Что обязан иметь каждый шаблон |

## Как добавить спеку

Файл называется по предмету, например `release-process.md`. В нём три части. Сначала требование одним предложением, потом причина, потом способ проверки. Если требование проверяется кодом, рядом появляется правило в `ast-grep/` или шаг в `mise-tasks/check`, а в спеке стоит ссылка на него. Требование без проверки в спеку не попадает, потому что агент читает её как факт.

Спека описывает то, что общее для нескольких репозиториев. Правило одного шаблона записывается в его собственный `README.md` или `AGENTS.md`.
