# Контракт шаблонов

Требования, общие для всех шаблонов в `repos/`.

## Требования

1. **В `Makefile` каждого шаблона есть цель `install`.** Она ставит зависимости, и одинаковая команда `make install` позволяет агенту подготовить любой клон, не читая его документацию. Проверяет задача `mise run check`, она ищет строку `install:` в `Makefile` клона.
2. **В коде шаблона нет `console.log`.** Код, который копируют в новый проект, не должен тащить в него отладочный вывод. Проверяют правила `no-console-log-js` и `no-console-log-ts` из `ast-grep/rules/`. Тесты, `bin/` и каталоги `test` и `__tests__` под правило не попадают.

## Что в контракт не входит

Цели `test` и `lint` обязательными не сделаны, в `fastify-api-application` на момент записи нет цели `test`. Новое требование добавляется здесь вместе с проверкой.

## Как менять контракт

Новое требование идёт вместе с проверкой. Правило оформляется по скиллу `add-ast-grep-rule`, а решение, которое влияет на все шаблоны, записывается в `docs/adr/`. Клоны правят в их репозиториях отдельными коммитами.
