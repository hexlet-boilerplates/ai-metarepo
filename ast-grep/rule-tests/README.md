# rule-tests

Тесты правил. Для правила `<id>` лежит файл `<id>-test.yml` с полем `id` и двумя списками.

- `valid` перечисляет код, на котором правило молчит.
- `invalid` перечисляет код, на котором правило срабатывает.

Тесты запускает `ast-grep test --skip-snapshot-tests`. Флаг отключает снимки, они нужны для проверки текста сообщений и здесь не используются. Тот же запуск стоит в хуке pre-commit (`hk.pkl`) и в задаче `mise run check`.
