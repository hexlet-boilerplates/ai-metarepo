# rules

Правила ast-grep, по файлу на правило. Ast-grep читает только `*.yml`, поэтому этот README ему не мешает.

Имя файла совпадает с полем `id` внутри. В шапке файла комментарий отвечает на вопрос, почему правило есть. Поле `ignores` исключает места, где нарушение допустимо (тесты, `bin/`). Серьёзность `error` роняет `mise run check`, `warning` только печатает.

Новое правило добавляется по скиллу `add-ast-grep-rule` вместе с тестом в `../rule-tests/`.
